# Random Walk

This Program should be compiled with `-lSDL3` linker flag.

The executable will create a window that populates *random walkers* starting from the center of the launched screen (canvas).
You can manipulate these values:

1. The number of random walkers. (`-N 10000`)
2. The *width* of the canvas. (`-W 800`)
3. The *height* of the canvas. (`-H 600`)
4. The *move style* of the walkers. (`-wms s`)
5. The *trail* behaviour. (`--no-trail`)
6. The *size* of the walker. (`-A 5.0`)
7. The *length* of the **trail**. (`-TL 1000`)
